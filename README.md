 📊 Power BI Dashboard Project

 📌 Overview
This project is an interactive Power BI dashboard created as part of my data analytics learning journey.

It helps transform raw data into meaningful insights using visual analytics and structured reporting.

 📊 Dashboard Features

- KPI overview cards for key business metrics  
- Trend analysis using line charts  
- Category comparison using bar and clustered bar charts  
- Distribution analysis using pie and donut charts  
- Hierarchical breakdown using tree structure  
- Geographical insights using map visual.

   🛠 Tools Used

- Power BI  
- Microsoft Excel (Data Preparation)


 🎯 Key Learnings

- Building a complete dashboard from scratch  
- Selecting appropriate visualizations for different data types  
- Converting raw data into actionable insights  
- Designing a clean and structured analytics flow  
- Understanding business intelligence basics
